# Logo usage

The authoritative rules are in `guidelines/URBIVA_Logo_Guidelines_v1.0.pdf`. Summary:

## Do

- Use the supplied files. The SVG files have outlined text and need no font.
- Keep clear space equal to the height of the central hexagon on every side.
- Use Volt Lime icon with Porcelain wordmark on Midnight Violet, or Midnight Violet on Porcelain White.
- Use the monochrome versions when only one colour is available.
- Scale proportionally.

## Do not

- Redraw, retype or re-space the wordmark, or set it in capitals.
- Recolour the icon outside the approved palette, add gradients, outlines or shadows.
- Stretch, rotate or crop the icon.
- Place the logo on busy photos without a solid backing.
- Rebuild the icon from text characters or other shapes.

## Minimum sizes

Follow the minimum sizes in the guidelines PDF. On GitHub, the avatar is tested at 64, 40, 32 and 20 px (`github/png/urbiva-avatar-preview.png`).
