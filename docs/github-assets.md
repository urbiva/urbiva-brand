# GitHub asset specifications

All assets are in `github/svg` (masters) and `github/png` (renders), generated by `python3 github/generate.py` (needs `rsvg-convert` and the Manrope, Inter and IBM Plex Mono fonts installed).

| Asset | Size | Files | Use |
| --- | --- | --- | --- |
| Organization avatar | 1024 × 1024, 512 × 512, 64 × 64 | `urbiva-avatar-{dark,light,transparent,mono}` | Organization settings; dark is primary |
| Avatar preview | 1400 × 620 | `urbiva-avatar-preview` | Circular crop and small-size check |
| Profile banner | 1600 × 500 master, 1280 × 400 README | `urbiva-banner-{dark,light}` | `.github/profile/README.md` |
| Social preview | 1280 × 640 | `social-<repo>-{dark,light}` | Repository Settings, Social preview |
| Repository header | 1600 × 400 | `header-<repo>-{dark,light}` | Top of each README |
| Architecture | 1600 × 940 | `urbiva-architecture-{dark,light}` | Profile and docs |
| Module cards | 760 × 380 | `module-{go,vision,urban,impact}-{dark,light}` | Profile README |
| Divider | 1600 × 48 | `divider-{dark,light}` | Between README sections |
| Status labels | auto × 36 | `status-{implemented,sample,planned,research}-{dark,light}` | Inline status |
| Feature template | 1600 × 900 | `feature-template-{dark,light}` | Feature previews with a screenshot |

## Rules

- The icon and wordmark come from `logos/` master geometry, scaled uniformly; never redrawn.
- The avatar icon is 560 px tall on a 1024 canvas, centred with an 8 px optical lift, so it stays inside GitHub's circular crop.
- Use PNG in READMEs; GitHub sanitises SVG and may not load fonts.
- Use `<picture>` with `prefers-color-scheme` to switch Dark and Light renders.
- Every image in a README needs meaningful alt text.
- Never add performance numbers that have not been measured.
